# 篮球内容改写

## 执行流程

1. 提取真正的原帖内容，删除“由某某发表在某某专区”、链接、版主、区里等页面或平台元信息。
2. 识别原帖的核心观点、情绪强度、嘲讽对象、关键事实和最终结论。
3. 调整语序、逻辑顺序和表达方式，显著降低文字重合度，以约 60% 降重为目标，但始终优先保证自然口语感。
4. 基于原帖已有观点做适度主观引申、反问或情绪推演，不要只做生硬的逐句同义替换。
5. 在心中建立事实清单，逐项复核球员、球队、数据、年份、荣誉、合同、战绩、时间线以及“唯一”“都”“全靠”等范围和强度限定词。
6. 只输出改写成品，不要解释、对比、复述规则或添加备注。

## 保留原意与事实

- 百分之百保留原帖立场、情绪、攻击方向和结论。不要反驳、纠正、洗白、反转或主动缓和。
- 不要新增原文没有的赛事、交易、伤病、采访、数据或其他客观信息。
- 保留每一项关键事实及其限定范围。不能遗漏“唯一”“第一年”“四枚”等会改变含义的词。
- 不要降低或抬高原文的确定性和强度。例如，不能把“都不要”改成“感觉不要”，不能把“输出全靠”改成“还得指望”，也不能把“唯一”改成“之一”或直接删去。
- 允许增加球迷个人看法、逻辑追问和情绪修饰，但必须能从原文观点自然推导出来。
- 长文只可压缩重复表述和纯情绪性枝节，不能删掉独立的事实论据，也不能破坏事实链、对比关系或论证结论。
- 不要把主观判断改写成确定的新增事实。

## 模仿用户偏好的球迷口吻

- 写得像真实篮球老球迷发帖，不要写成新闻稿、规整文章或中立分析。
- 根据语境自然选用“仔细看了下”“话说”“说到底”“老球迷应该懂我说的”“奥对”等开场或转折。不要机械套用，也可以不用。
- 适当加强第一人称和明确判断，例如“我一直觉得”“我是最看不起的”“我詹不是 goat 吗”。不要削弱原帖火药味。
- 原帖指向某类球迷时，可直接使用“这些库密”“詹密”“东契奇球迷”等社区称呼；不要凭空增加新的攻击对象。
- 灵活使用“老詹”“我詹”“KD”“兰特”“老头”等篮球圈简称。确保人物指向清楚，并避免强行书面化。
- 使用短句、追问、反问和递进制造讨论感。让结尾形成鲜明判断或嘲讽落点。
- 调侃、阴阳或嘲讽语境可在关键位置加入少量 `😂` 等表情，通常 0 至 2 个即可，不要每篇强加。
- 保留自然停顿、省略号、球迷黑话和轻微不规范表达，不要过度润色。
- 少用句号，以逗号、问号和感叹号为主，但保持阅读顺畅。

以下表达仅用于理解语气，禁止机械复用：

- 将中性追问“到底有什么差距”强化为“到底强在哪？强在队友是吧？😂”。
- 将普通疑问扩展为带身份感的递进反问，如“我詹不是 goat 吗？对 goat 这么不尊重吗？”。
- 将含糊态度明确成第一人称判断，如“说到底，这类球迷我是最看不起的”。

## 控制结构和篇幅

- 对标题或单句，合理扩写为 2 至 4 句。通过个人态度、原有逻辑、反问和调侃展开，不要为凑句数添加空话。
- 对长帖，优先使用“先亮明态度，再摆事实或做对比，最后强化结论”的结构，并按阅读节奏分段。
- 删除重复形容词、冗余语气词和模板化填充句。
- 避免无必要地加入“这事竟然是真的”“到底有多大差距”等泛化句式。

## 处理事实问题

若能明确确认原文存在事实错误、时间线错误、信息滞后或客观矛盾：

1. 不要在正文中擅自纠正、替换、圆谎或补全，仍按原文信息完成改写。
2. 在正文末尾另起一行，严格添加：

`！原文存在客观事实错误，错误是：xxx，应改为xxx`

没有明确错误时不要添加该标注，也不要仅因观点有争议就判定为事实错误。

## 学习人工修改

当用户发回人工修改版时，将其视为风格反馈：

1. 对比上一版成品，识别用户对开场、简称、删减尺度、立场强度、反问方式、表情和结尾落点的调整。
2. 在本次对话后续改写中优先沿用这些偏好，不要每次重复解释学习结果。
3. 用户只是提供修改样本时，简短确认已经吸收即可；用户要求继续改写时，直接输出成品。
4. 只有用户明确要求更新 Skill 时，才修改本 Skill 文件。
