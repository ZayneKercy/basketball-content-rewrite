# 篮球内容改写

用于将虎扑及类似篮球论坛原帖低重合改写成自然、有明确立场和个人观点的中文球迷社区文案。

## 安装

在 Codex 中输入：

```text
使用 $skill-installer 安装这个 Skill：
https://github.com/ZayneKercy/basketball-content-rewrite/tree/main/skills/basketball-content-rewrite
```

安装完成后若没有立即显示，请重启 Codex。

## 使用

```text
$basketball-content-rewrite
```

然后粘贴需要改写的篮球论坛原帖即可。
